# SCAVANGER 로드맵 (2026-09-05 기획 반영)

기획 원문을 구현 단계로 정리한 문서. 각 단계는 `src/shared` 계약을 먼저 확정한 뒤 폴더별 병렬 에이전트로 구현하고,
단계마다 `npm run typecheck` + 헤드리스 스모크 테스트를 통과해야 다음 단계로 넘어간다.
영구 진행(창고, 기업 신뢰도, 레벨/스탯)은 **localStorage** 에 저장한다 (키 접두어 `scav.`).

상태: ☐ 미착수 · ◐ 진행 중 · ☑ 완료

---

## Phase 0 — 소규모 수정 ☑
- ☑ 스태미나 게이지를 화면 중앙 하단으로 이동, 꽉 찼을 때 완전히 숨김 (`ui/hud/Vitals`, `.stamina`).
- ☑ 정조준 시 캐릭터가 크로스헤어와 겹치지 않도록 카메라를 어깨 바깥쪽·위쪽으로 (`player/CameraRig`: `ADS_SHOULDER` 0.68, `ADS_PIVOT_LIFT` 0.22).

## Phase 1 — 무기 패키지 ☑ (2026-09-05)
소유 폴더: `items` (데이터) · `inventory` (UI/그리드/소켓/가방) · `weapons` (내구도 소모, 3슬롯, 소켓 효과, 탄약) · `ui` (HUD 슬롯 표기, 등급) · `hub` (수리 벤치) · `net` (스냅샷 `w`/슬롯).

### 1-a 총기 내구도
- `ItemInstance.durability?` (0..max). 발사 1발당 `WEAPON_DURABILITY_PER_SHOT` 소모, 0이 되면 발사 불가(불발음 + "내구도 없음").
- `WeaponDef.maxDurability` (등급에 따라 증가). HUD 무기 패널에 내구도 바.
- 함선 **정비 벤치**(개인/공유 함선 모두, `hub_workbench` interactable) → 수리 UI: 재료(폐금속/합금 판) 소모, 내구도 회복.

### 1-b 총기 등급
- `WeaponDef.grade: 1..5` (I 일반 · II 고급 · III 희귀 · IV 서사 · V 전설). 이름 뒤 로마 숫자 부착(`기관단총 III`). `Rarity` 와 1:1 매핑.
- 등급 ↑ → 발당 대미지 ↑, 최대 내구도 ↑. 각 클래스(SMG/AR/SG/SR/DMR/HG)당 5등급 데이터 생성 (`WeaponDefs` 빌더).
- 종류 라벨: 기관단총(SMG), 돌격소총(AR), 산탄총(SG), 저격소총(SR), 지정사수소총(DMR), 권총(HG, 보조).

### 1-c 탄약 종류
- `AmmoType` = `light`(경량탄, SMG) · `medium`(준중량탄, AR) · `heavy`(중량탄, SR/DMR) · `shell`(산탄) · `pistol`(권총탄, HG). 기존 `rifle/pistol/shotgun/energy` 는 별칭으로 유지(append-only).
- 탄약 팩 아이템 갱신, 로그 드랍 테이블에 사용.

### 1-d 주무기 2종 + 보조무기
- `Loadout = { primary1, primary2, secondary }`. 키: 1 = 주무기 I, 2 = 주무기 II, 3 = 보조무기 (Q = 이전 무기).
- 주무기 교체 0.4 s, 보조무기 교체 0.1 s + ADS 시간 절반.
- 인벤 장착 컬럼 3칸. `loadout:changed` 페이로드에 `primary2` 추가.

### 1-e 무기 소켓
- `ItemInstance.sockets?: Partial<Record<SocketSlot, ItemInstance>>`; `SocketSlot = 'muzzle' | 'grip' | 'mag' | 'stock' | 'sight'`.
- 부착물 아이템 카테고리 `attachment` + `AttachmentDef` (슬롯, 효과, 허용 클래스, 호환 탄약).
  - 총구: 제동기(수직/수평 반동 −), 보정기(탄퍼짐 −), 산탄총 초크(SG 전용 탄퍼짐 −)
  - 그립: 앵글 그립(수평 반동 −), 수직 그립(수직 반동 −)
  - 탄창: 확장형 경량/준중량/중량/산탄 탄창(탄창 용량 +)
  - 개머리판: 탄퍼짐 −, ADS 시간 −
  - 조준경: 레이저사이트(힙 탄퍼짐 −), 4×/6×/8× 조준경(`adsZoom`, `scope`)
- 인벤에서 부착물을 무기 타일에 드래그 → 장착(이미 있으면 교체, 기존 부착물은 가방으로). 무기 툴팁에 소켓 상태.
- 무기 우클릭 메뉴: 버리기 · 장전된 탄약 모두 탈착(탄약 팩으로 반환) · 소켓 모두 탈착.
- `weapons`: 소켓 효과를 합산한 `EffectiveWeaponStats` 로 발사/반동/ADS 계산.

### 1-f 가방
- 장착 슬롯 `bag`. `BagDef { rarity, cols, rows, quickSlots }`. 전설 = 현재 10×6, 일반 = 절반(5×6), 미장착 = 일반의 절반(5×3). 전술 가방 변형은 칸이 조금 좁고 빠른 사용 슬롯 +3 (Phase 2 휠슬롯과 연동).
- 가방 교체로 칸이 줄면, 줄어든 영역에 걸친 아이템은 즉시 월드 드랍(`inventory:itemDropped`).

## Phase 2 — 사망/부활 · 휠슬롯 · 수류탄 코킹 ☑ (2026-09-06)
구현 메모: 사망은 더 이상 임무 실패가 아님(솔로/분대 공통, `MISSION_FAILS_WHEN_ALL_DEAD = false`). 휠 슬롯 해금 순서는 `QUICK_SLOT_UNLOCK_ORDER`(N, S, E, W, 대각선) — 일반 가방 2칸 = 위/아래. 이벤트 이름은 `player:respawn` / `game:respawn` / `game:respawnAvailable` (기획의 `player:respawnReady` 대신). 검증: `node scripts/smoke-phase2.mjs` 44/44.
소유 폴더: `player` (전투불능/부활/기어다니기/코킹 포즈), `weapons` (수류탄 장착·코킹·언더쓰로), `ui` (휠슬롯, 곡선 코킹 게이지, 부활 프롬프트), `inventory` (소모품 슬롯), `enemies` (전투불능 무시), `net` (`PlayerFlags.DOWNED`, `revive` 메시지), `game` (완전 사망 → 30 s 리스폰).

### 2-a 전투불능(다운) / 부활
- 체력 0 → `downed` 상태: 별도 다운 체력 100, 1 초마다 1 감소, 포복 이동만 가능, 무기 사용 불가.
- 적 AI 는 다운된 플레이어를 목표로 삼지 않음(`CombatTarget.downed`). 오사/광역 피해로는 죽을 수 있음.
- 아군이 3 m 이내에서 E 10 초 홀드 → 부활(체력 10). 멀티: `revive` 요청/진행/완료 메시지.
- 완전 사망 → 30 초 후 부활 가능(시작 지점에서 헬포드로 재강하). 솔로: 다운 체력 소진 시 사망 화면 대신 30 초 카운트다운 → 리스폰.
- 이벤트: `player:downed`, `player:revived`, `player:respawnReady`.

### 2-b 휠슬롯 (빠른 사용)
- 8방향 휠(상하좌우+대각). 빠른 사용 키(F, 기존 회복약 키) 짧게 → 마지막 빠른 사용 아이템을 손에 장착, 좌클릭으로 사용. 꾹 누르면 휠 표시 → 커서로 선택 후 떼면 장착.
- 1/2/3 으로 총기 복귀. 가방 UI 에 소모품 슬롯 8칸(아크 레이더스식, 슬롯마다 고정 휠 위치). 가방 등급에 따라 활성 슬롯 수.
- 회복약·수류탄 등 `consumable` 이 대상. `Keys.GRENADE`(G) 는 Phase 3 함선 호출 휠로 재배정.

### 2-c 수류탄 코킹
- 수류탄 장착 → 좌클릭 누르면 던지기 포즈, 이때 R 로 안전핀 제거(코킹 시작, 에임 우측 곡선 게이지). 코킹 3 초 후 강제 폭발. 좌클릭 떼면 투척.
- 우클릭 = 오버/언더쓰로 토글(언더쓰로: 낮은 속도, 짧은 거리).
- 멀티: `grenade` 메시지에 `fuse` 잔여 시간 필드 추가.

## Phase 3 — 함선 호출(스트라타젬) · 화면 밖 인디케이터 ☑ (2026-09-06)
구현 메모: 신규 `src/stratagems/`(시스템 + 절차적 비주얼), `WorldRef.addObstacle` + `Obstacle.destructible`(구조물 체력 2000, 총알/수류탄 피해), 보급 상자 = 아이템 루팅 티어 5, 멀티는 `strat call`(seed 로 동일 배치) + `structHp` 동기화, 적 피해는 호출자 클라이언트의 `applyExplosion` 경유. 검증: `smoke-phase3.mjs`, `smoke-stratagems.mjs` 51/51.
소유 폴더: 신규 `src/stratagems/` (호출 상태기계, 궤도 레이저/항공 폭탄/보급/구조물 오브젝트, 톱뷰 타겟팅), `ui` (휠, 쿨다운, 오프스크린 인디케이터), `enemies` (구조물 충돌 피해, 레이저 피해), `world` (구조물 콜라이더 등록), `net` (`strat` 메시지, 호스트 판정).

- G 홀드 → 함선 호출 휠. 모든 호출은 **공유 쿨타임**.
- 궤도 폭격(90 s): 좌클 3 초 홀드 → 톱뷰 카메라 → 위치 지정(Esc/우클 취소) → 5 초 후 10 초간 굵은 레이저 빔, 피아 무구분.
- 항공 폭탄(90 s): 동일 타겟팅 → 5 초 후 대형 폭발.
- 보급품 투하(60 s): 현재 시점에서 지면 범위 지정 → 3 초 후 보급 상자 낙하(랜덤 소모품, 낙하 충돌 시 대미지).
- 구조물 투하(60 s): 범위 내 엄폐 구조물 5개 산개 낙하, 피격 적 대미지, 체력 2000, 파괴 가능.
- 오프스크린 인디케이터: 화면 밖 수류탄, 5 초 이내의 아군 핑(이후 맵/나침반만), 도착 전까지의 함선 호출 목표.

## Phase 4 — 인간형 적(로그) · 적 기믹 · 시체 루팅 ☑ (2026-09-06)
구현 메모: 로그는 `ctx.world.getCrates()` 의 2등급 이상 상자 주변에 분대로 배치(보스 1 + 호위 3), 진영(`EnemyFaction`) 간 교전은 enemies 내부 `CombatTarget('ai')` 로 처리. 곡사체는 `InterceptableRef` 로 노출되어 weapons 가 격추. 거대껍질은 `EnemyHit.armored` + `ARMOR_IMMUNE_AMMO` 로 경량/준중량/산탄 면역. 시체는 `corpse:<id>` 인터랙터블 → `openContainerItems(rollCorpse(...))`, 내용물은 클라이언트별. 검증: `smoke-phase4.mjs`.
소유 폴더: `enemies` (로그 AI/모델, 곡사포·맹독충·거대껍질·보스 로그, 진영 적대), `world` (상자 지킴 배치, 시체 인터랙터블), `items` (로그 드랍 테이블), `weapons` (곡사체 요격 히트박스), `net` (새 `EnemyType`, 진영).

- 로그: 총기 사용 인간형. 낮은 반응속도, 불안정한 에임, 단순 엄폐 사격 AI, 가끔 뛰쳐나와 근접 사격. 주로 상자 루팅 장소를 지킴.
- 모든 적은 시체를 남기고 루팅 가능(`corpse` 컨테이너). 로그는 사용 총기 탄약 + 내구도 매우 낮은 총기 드랍.
- 버그 ↔ 로그 적대(진영 `faction`), 마주치면 전투.
- 곡사포 버그: 원거리 정지 후 느린 곡사체 발사, 사격으로 요격 가능.
- 맹독충: 독낭 보유, 접근 후 자폭(피아 무구분), 사살 시 그 자리 폭발.
- 거대껍질버그: 4배 크기, 전면 껍질은 경량/준중량/산탄 면역, 직선 돌진(피격 시 큰 피해 + 측면 넉백). 중량탄/수류탄/후방 사격으로 피해.
- 보스 로그: 1.5배 크기, 체력 5배, 일반 로그 3마리 동행.

## Phase 5 — 메타 진행 ☑ (2026-09-06 — 상세 계획: `docs/PHASE5-PLAN.md`, 실행 브리프 §8)
구현 메모: 5-b XP/레벨과 5-a 창고는 tactical-kit 병합·컨트롤 패키지에서 먼저 들어왔고, 남은 5-c(기업·신뢰도·계약·퀘스트·크레딧·상점·함선 컴퓨터, 신규 `src/meta/`)와 로드아웃 영속화(`scav.loadout`), 결과 화면 XP 정산은 2026-09-06 에 완료. 스탯 효과 5종은 `DerivedStats` 그대로(스킬 북 제외), 레벨당 스탯 1 포인트, `XP_BASE` 120, 창고 상한 = 그리드. 검증: `smoke-meta` 90/90, `smoke-loadout` 45/45, `smoke-ui-p5` 52/52, `smoke-ship-rooms` 61/61.
결정(2026-09-06): 스탯 효과는 후순위(XP/레벨/포인트 적립만), 기업 이름·상점·계약·퀘스트 초안은 계획서에 작성, 행성 기믹(5-d)은 별도 세션.
소유 폴더: 신규 `src/meta/` (localStorage 저장소: 창고, 로드아웃, 기업/신뢰도/계약/퀘스트, 레벨/스탯), `hub` (창고 UI 호출, 컴퓨터 인터랙터블, 행성 선택), `inventory` (3열 창고/장착/가방 UI), `ui` (레벨업/계약 정산 결과 화면), `world` (행성 기믹: 기차·레일, 버려진 화물차), `game` (경험치 정산, 퀘스트 트리거).

### 5-a 개인 함선 창고 & 로드아웃
- 개인/공유 함선 어디서나 Tab → 좌: 함선 창고, 중앙: 장착, 우: 인벤토리. 로드아웃 세팅 후 포드 탑승.
- 탈출 성공 시 가방 내용물 → 창고. 사망 시 소실.

### 5-b 스탯 포인트 / 경험치
- 레이드 행동(처치, 상자 조사, 미션, 퀘스트)으로 경험치. 레벨업당 스탯 포인트 3. (스탯 종류는 기획 미정 — 확정 필요)

### 5-c 기업 · 신뢰도 · 계약 · 퀘스트
- 개인 함선 컴퓨터 → 기업 A/B(총기·탄약), C(가방), D(소모품). 신뢰도 0 = 판매 없음, 1부터 상점 해금, 레벨↑ → 가격↓·등급↑.
- 계약: 플레이어당 한 기업. 행동 기반 목표, 탈출 시 정산. 분대원의 계약 행동에 25 % 신뢰도 공유.
- 퀘스트: 아이템 수집/특정 행성 상호작용, 선행 조건(신뢰도 레벨, 이전 퀘스트) 연계. 기업 접촉으로 보고·완료.

### 5-d 행성 기믹
- 기차·레일: 맵 외곽 레일, 재료 투입으로 작동, 전/후진, 탑승 이동.
- 버려진 화물차: 행성당 1대, 탈출구 지정 시 이동, 도착 시 6배 크기 상자 개방.
