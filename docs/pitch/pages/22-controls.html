조작

키보드 · 마우스 기본 레이아웃. 콘솔 패드 대응을 전제로 동시 입력 수를 억제해 설계했다.

키동작
WASD이동 · Shift 질주 · Ctrl 앉기 · Z 엎드리기 · Space 점프
마우스 좌 / 우사격 / 정조준
R · V재장전 / 근접 공격
123주무기 I · 주무기 II · 보조무기
F빠른 사용 — 짧게 누르면 최근 아이템, 홀드하면 8방향 휠
Q전술 임플란트 발동
G함선 호출 — 홀드하면 휠, 탭하면 마지막 호출 재장전
E상호작용 (상자 · 콘솔 · 시체 · 아군 부활은 홀드)
Tab인벤토리 / 캐릭터 / 기업 / 함선 탭 화면
M · Enter지도 / 채팅
Alt커서 모드 (포인터 락 해제 — 핑 · UI 조작)
Esc일시정지 · 열려 있는 화면 닫기

모든 키는 리바인딩 가능하다.
