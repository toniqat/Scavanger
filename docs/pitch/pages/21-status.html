8.2기술 스택

항목내용
엔진Three.js 0.185 · TypeScript (strict) · Vite
에셋외부 에셋 파일 0개. 플레이어 · 벌레 · 상자 · 함선 · 소품 전부 코드에서 지오메트리로 절차 생성. 텍스처도 절차 Canvas.
UI순수 DOM + CSS. React 없음.
네트워크Node ws 릴레이. 20 Hz 스냅샷, 호스트 권한 판정, 프로필/레이드 세션 서버 저장.
배포브라우저 · Electron 포터블 실행 파일. 싱글 플레이는 서버 없이 localStorage 만으로 동작.
목표 성능적 60마리 동시에 60 fps
절차 생성 파이프라인의 의미. 아트 에셋이 하나도 없으므로 아티스트 없이도 기능 검증이 끝난다. 캐주얼 아트 스타일로 갈아입히는 작업은 게임플레이가 확정된 뒤 별도 트랙으로 진행할 수 있다 — 프로토타입 단계의 리스크를 크게 줄이는 선택.
